# 시스템 구조 개요

```text
                   +---------------------+
                   |  FastAPI Router     |
                   +----------+----------+
                              |
        +---------------------+---------------------+
        |                     |                     |
+-------v--------+   +--------v--------+   +--------v--------+
| 채용공고       |   | Identity/Auth   |   | 감사 로그       |
| model/schema  |   | user/hash/JWT   |   | 보안 이벤트     |
| service       |   | dependency      |   | 영속화           |
+-------+--------+   +--------+--------+   +--------+--------+
        |                     |                     |
        +---------------------+---------------------+
                              |
                    +---------v---------+
                    | SQLAlchemy        |
                    | SQLite/PostgreSQL |
                    +-------------------+

외부 공급자: FixtureProvider -> 채용공고 <- SaraminProvider(승인·구현 대기)
```

1. 현재 배포 단위는 하나입니다.
2. 각 도메인은 service/model/schema 경계로 분리합니다.
3. 외부 채용 API는 adapter 계층으로 격리합니다.
4. MSA 전환은 현재 요구사항이 아니라 미래의 조건부 선택입니다.
