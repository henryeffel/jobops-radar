# ADR-0009: Microservices 대신 Modular Monolith 선택

## 상태
승인됨

## 배경
- 개발자와 배포 단위가 각각 하나입니다.
- 현재 트래픽이 낮습니다.
- 분산 배포보다 도메인 검증이 중요합니다.

## 결정
명시적인 도메인 경계를 가진 Modular Monolith를 사용합니다.

## 검토한 대안
1. Microservices
2. 도메인 경계가 없는 Layered Monolith

## 결과
장점은 운영 복잡도가 낮고 통합 테스트가 쉬우며 향후 분리 지점이 명확하다는 것입니다.

단점은 독립적으로 배포할 수 없고 데이터베이스 경계를 공유한다는 것입니다.

## 전환 조건
- 도메인별로 독립된 팀이 소유할 때
- 확장 또는 장애 격리 요구사항이 서로 달라질 때
- 데이터 소유권을 분리해야 할 때
