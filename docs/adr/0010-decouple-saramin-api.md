# ADR-0010: Saramin API 의존성 분리

## 상태
승인됨

## 배경
공식 API 승인은 프로젝트 외부 요인이며 제품 검증을 지연시킬 수 있습니다.

## 결정
Provider interface를 정의하고 현재는 수동 fixture adapter를 사용합니다. 공식 Saramin 연동도 향후 같은 경계 안에서 구현합니다.

## 검토한 대안
1. 승인될 때까지 개발 중단
2. 웹사이트 scraping

## 결과
외부 승인 없이 결정론적으로 개발할 수 있습니다. 반면 fixture 최신성은 수동으로 관리해야 하며 공급자별 데이터 정규화는 후속 작업으로 남습니다.

## 전환 조건
- 공식 인증 정보와 안정적인 응답 계약을 확보할 때
