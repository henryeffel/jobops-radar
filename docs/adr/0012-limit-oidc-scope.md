# ADR-0012: OIDC 구현 범위 제한

## 상태
승인됨

## 배경
표준을 준수하는 OIDC Provider에는 discovery, 키 관리, authorization flow, 동의, client 등록, 광범위한 보안 검토가 필요합니다.

## 결정
OIDC Provider를 구현하거나 구현했다고 주장하지 않습니다. 먼저 회원가입·로그인·현재 사용자 조회를 완결하고 OIDC는 설계 경계로만 기록합니다.

## 검토한 대안
1. 부분적인 자체 OIDC 구현
2. 제출 범위 확대

## 결과
보안 관련 주장과 실제 검증한 동작이 일치합니다. 반면 외부 연합 로그인은 사용할 수 없습니다.

## 전환 조건
- 구체적인 Relying Party 사용 사례와 운영 수준의 Provider 전략을 확보할 때
