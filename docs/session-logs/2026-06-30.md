DSA는 사용하지 않았습니다. 가장 가까운 CS 개념은 진행 상황 분해입니다. 코드 줄 수가 아니라 완료된 아키텍처·제품 역량을 기준으로 프로젝트를 평가했습니다.

### 설계 결정

### 문제와 주의사항

- PostgreSQL, Saramin, CI/CD, 배포는 당시 검증 또는 구현되지 않았습니다.
- 과거 Windows pytest workaround가 기록되어 있지만 test에서 고정된 base temp 경로를 사용하지 않아야 합니다.
