# AI 협업 개발

## AI를 사용한 작업

- 반복 코드와 문서 초안 작성
- 테스트 및 누락된 경계 조건 제안
- Migration 검토 보조

## 사람이 결정한 항목

- 도메인 경계와 인증 범위
- Token claim, 비밀번호 정책, 감사 데이터 최소화
- 최종 코드 검토와 한계 수용 여부

## 판단 사례

Refresh token은 의도적으로 제외했습니다. 불완전한 세션 생명주기를 추가하기보다 검증 가능한 로그인 흐름을 완성하는 데 우선순위를 두었습니다.

## 검증 원칙

- AI가 작성한 변경 사항은 사람이 최종 검토합니다.
- 보안에 민감한 동작은 정상·실패 경로를 모두 테스트합니다.
- Prompt에 인증 정보나 비밀 키를 포함하지 않습니다.
